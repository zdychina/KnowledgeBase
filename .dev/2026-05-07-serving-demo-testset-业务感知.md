# Serving Demo 评分题库：业务感知功能描述

- 生成时间：2026-05-07
- 目标：为 `data\knowledge_base\业务感知功能描述` 构建一套**可分层、可打分、可演示**的 Serving 测试题库
- 适用场景：
  - 检查基础定义与术语召回是否正常
  - 检查流程、规则、场景类问题能否命中多个知识块
  - 检查 `raw_text + generated_question + relations` 是否能支撑综合知识消费

## 使用原则

这套题库分成 4 个难度层级：

- `L1 基础事实题`
  - 检查最基本的定义、术语、枚举点能否命中
- `L2 解释理解题`
  - 检查系统能否解释概念差异、机制区别
- `L3 流程与规则题`
  - 检查系统能否把多个步骤或规则逻辑串起来
- `L4 综合推理题`
  - 检查系统能否把背景、概念、流程、规则、场景联合召回

## 建议打分方式

每题建议按 0-5 分打分：

- `5 分`
  - 命中核心答案段
  - 命中 2 个以上辅助证据段
  - 多文档支撑明显
  - 结果结构清晰，可直接演示
- `4 分`
  - 命中核心答案段
  - 有辅助证据，但还需人工轻微拼接
- `3 分`
  - 只命中部分关键段
  - 方向对，但不够完整
- `2 分`
  - 只命中局部术语或单一片段
  - 无法支撑完整回答
- `1 分`
  - 只命中边缘相关内容
- `0 分`
  - 基本未命中或明显跑偏

## 总分建议

- 全题库满分：`100`

  - `L1` 中 3 题
  - `L2` 中 3 题
